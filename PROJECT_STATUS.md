# PROJECT_STATUS

## 1. Краткое описание

Проект представляет собой Angular SPA-приложение в формате визуальной новеллы / story-driven семейного путешествия с персонажем-проводником Пампалче.

Текущая версия уже является работающим MVP, в котором:

- есть 4 последовательных модуля;
- контент вынесен в JSON;
- прохождение сохраняется локально;
- доступны диалоги, выборы, тесты, кроссворд, творческие ответы и фото;
- есть экран наград и финальный сертификат.

Приложение ориентировано на:

- детей 6–10 лет;
- родителей;
- совместное прохождение в формате семейного досуга.

## 2. Образовательная концепция

### 2.1. Актуальность

Проект отвечает задаче укрепления семейных ценностей через совместный досуг. В приложении ребенок и взрослый не просто проходят задания рядом, а читают, обсуждают, создают общий результат и принимают решения вместе.

### 2.2. Главная образовательная цель

Главная цель проекта — формирование семейных ценностей, укрепление внутрисемейных отношений и организация содержательного совместного досуга через сказку, творчество, игру со словами и кулинарию.

### 2.3. Педагогическая основа

В текущей концепции приложения используются такие опоры:

- семейное чтение как основа для разговора о ценностях;
- совместное творчество как форма детско-родительского взаимодействия;
- мягкая рефлексия после выполнения задания;
- культурный контекст народа мари как содержательная тема путешествия;
- игровые задания как способ удержания внимания ребенка младшего школьного возраста.

### 2.4. Семейные ценности, которые поддерживает проект

Приложение системно опирается на следующие ценности:

- любовь;
- уважение;
- забота;
- доверие;
- взаимопомощь;
- благодарность;
- преемственность поколений.

### 2.5. Культурная значимость

Содержательная основа путешествия связана с культурой народа мари. Это выражается через:

- сказочную героиню Пампалче;
- мотивы семейного тепла и домашнего уклада;
- мастер-класс по оберегу;
- словесные и смысловые задания;
- финальный кулинарный модуль с национальным блюдом.

## 3. Персонаж Пампалче

Пампалче в проекте — не декоративный герой, а центральный проводник семейного маршрута.

Ее роль:

- сопровождает пользователя между модулями;
- задает тон общения;
- помогает ребенку и взрослому обсуждать ответы;
- связывает образовательные задания с семейными ценностями;
- выступает символом теплого, безопасного и доброжелательного семейного пространства.

Ключевые характеристики персонажа:

- добрая;
- заботливая;
- смелая;
- защитница семьи;
- проводник между модулями;
- символ семейных ценностей.

## 10. Сертификат

Сейчас сертификат в приложении не просто визуальный экран, а механика завершения маршрута.

Условия получения:

- пройти все 4 модуля;
- собрать маршрут без пропуска;
- сохранить семейный результат как часть общего пути.

Сценарий:

1. Семья проходит все модули по порядку.
2. Пампалче «собирает» все искры путешествия.
3. Открывается финальный экран.
4. Пользователь получает сертификат и может его распечатать.
