# Asset Pipeline

Этот каталог подготовлен для пакетной генерации изображений ассетов.

Содержимое:

- `prompts/` — отдельный `.txt` на каждый ассет.
- `batches/imagegen_queue.json` — полная очередь генерации.
- `batches/imagegen_queue.jsonl` — та же очередь в построчном формате.
- `output/` — целевые папки для готовых изображений.
- `reviews/generation_status.json` — статус-файл для контроля генерации и отбора.

Текущий статус:

- промты и очередь созданы
- фактическая генерация не выполнена в этой сессии, потому что в окружении нет встроенного `image_gen`, нет локального генератора в проекте и не задан `OPENAI_API_KEY`

Следующий шаг:

1. Подключить генератор или CLI-бекенд.
2. Запустить batch по `batches/imagegen_queue.json` или `batches/imagegen_queue.jsonl`.
3. Сохранить финальные изображения в `output/`.
