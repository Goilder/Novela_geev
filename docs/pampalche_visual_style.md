# Pampalche Visual Style

## Основа

MVP держится на визуальном языке теплой сказочной educational visual novel. Интерфейс должен ощущаться дружелюбным и безопасным для ребенка 6-10 лет, но достаточно аккуратным для совместного прохождения с родителем.

## Палитра

- `#fbf5df` — светлый кремовый фон карточек
- `#c53932` — акцентный красный, кнопки и орнамент
- `#86bf35` — травяной зеленый для модульных секций
- `#6cb4e3` — озерный голубой для спокойных блоков
- `#4c3a2d` — теплый коричневый текст
- `#fff9ec` — мягкий фон под сертификат

## Принципы UI

- Крупная типографика с ясной иерархией
- Большие кнопки, читаемые поля ввода и заметные статусные плашки
- Мягкие стеклянные панели поверх сценических картинок
- Иллюстрации используются как атмосферный слой, а не как подложка под мелкий текст
- Пампалче остается эмоциональным центром через диалоговые карточки, фразы-поддержки и экранные переходы

## Компоненты

- `story-card`: базовая карточка-сцена с мягкой тенью и кремовым фоном
- `hero-panel`: крупный hero-блок меню и финального экрана
- `module-tile`: большая плитка модуля со статусом, искрами и CTA
- `step-card`: универсальная карточка задания внутри модуля
- `certificate-sheet`: печатный финальный сертификат

## Motion

- Легкое появление карточек снизу вверх
- Мягкие hover-состояния без резких скачков
- Никаких агрессивных анимаций и мигания
